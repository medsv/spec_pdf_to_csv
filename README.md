# Конвертация спецификации из формата PDF в формат XLSX
Исходные данные: <br>
pdf-файл со спецификацией из Рабочей документации (РД) (из файла РД следует извлечь листы спецификации и сохранить их в отдельный pdf-файл).

Результат работы приложения: <br>
xlsx-файл спецификации, созданный на базе шаблона `templates/Шаблон_спецификации_РД.xlsx`.
